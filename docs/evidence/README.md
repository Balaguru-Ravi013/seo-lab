# Baseline evidence artifacts

Captured from a local production server during Phase 3.

- `baseline-checks.json` — parsed HTML/HTTP checks
- `*.html` — initial HTML snapshots
- `lighthouse-*-summary.json` — condensed lab scores
- `lighthouse-*.report.html` / `.report.json` — full Lighthouse outputs

These files support `docs/baseline-audit.md`. Do not treat local Lighthouse scores as field CWV or ranking proof.
