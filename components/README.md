# Components

Shared UI for the Pacewright storefront.

- `layout/` — header, footer, page chrome
- `product/` — cards, gallery, specs, related products, breadcrumbs
- `filters/` — brand/category filters and sort controls
- `ui/` — small presentational primitives

Baseline and optimized branches should keep visual design aligned. SEO/AEO-only helpers may be added later on the optimized branch.
